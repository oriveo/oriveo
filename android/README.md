# Oriveo for Android

A native Android chat client for the AI models you already pay for. You add your own API keys, and
the app talks to each provider directly from the phone.

Conversations, notes, folders and skills are stored on the device. There is no account to create
and no server in the middle: the only thing the app fetches from us is a read-only model catalog
(capabilities and prices), and you can point that at your own host or turn it off entirely.

## What is in here

- **Providers**: OpenAI, Anthropic, Gemini, OpenRouter, DeepSeek, Grok, Groq, Together, Fireworks,
  MiniMax, Zhipu, Qwen, Moonshot, Mistral and SiliconFlow, each with your own key.
- **Relay**: any OpenAI-, Anthropic- or Gemini-compatible endpoint you run or subscribe to,
  including a model server on your own machine.
- **Subscription sign-in**: import a Grok or Codex subscription you already hold, instead of an
  API key.
- **Chat**: streaming, reasoning display, citations, attachments (images, PDFs, documents),
  quoting a selection, retry, regenerate and continue.
- **Skills**: reusable system prompts with their own model, parameters and reference documents.
- **Notes and folders**: capture a reply as a note, organise conversations, search across both.
- **Cost**: per-message and per-provider spend, computed on the device from what each response
  actually reported.
- **Backup**: export everything to a file you keep, and restore it.

## Building

Requirements: JDK 17, and the Android SDK. Android Studio Ladybug or newer works out of the box.

```bash
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
```

The build declares `minSdk 26`, `targetSdk 36` and `compileSdk 37`; the Android Gradle Plugin and
Kotlin versions are pinned in `gradle/libs.versions.toml`.

`local.properties` (your SDK path) is generated by Android Studio and is not committed. Release
signing is described in [SIGNING.md](SIGNING.md).

## The model catalog

The app reads model capabilities and prices from a public catalog so that a new model works
without an app update. It is a plain HTTPS GET with no credentials and no identifier attached, and
chat requests never go anywhere near it.

To serve it yourself, or to skip it:

```bash
./gradlew :app:assembleDebug -PORIVEO_METADATA_BASE_URL=https://your.host
./gradlew :app:assembleDebug -PORIVEO_METADATA_BASE_URL=
```

With an empty value the app runs entirely offline, using the catalog snapshot bundled at build
time.

## Layout

```
app/src/main/java/ai/oriveo/community/
  core/       data (Room), providers and transports, models, streaming, attachments
  feature/    one package per screen: chat, providers, notes, skills, settings, home
  ui/         shared components and theme
  di/         Koin modules
benchmark/    macrobenchmark suite
```
